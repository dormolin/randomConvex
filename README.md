# randomConvex
place convexes randomly

## How to build
To install dependencies:

```bash
bun install
```

To run test server:
```bash
bun start
```

To run test:
```bash
bun test
```

To release build
```bash
bun release
```

This project was created using `bun init` in bun v1.3.13. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.


## How to use
Deploy release build into any http/https server.

Access the server with modern browser.
Press 'generate'.

Options are placed in the side bar.
